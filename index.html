PALACE OF LIGHTS

SYSTEM III  :  GENERATIVE ARCHITECTURE

> Sequencer: 16-step Turing shift register. Chaos sets rewrite probability — fully left locks a repeating phrase, fully right rewrites every step.

> Oscillator: two detuned voices, each a continuous sine → triangle morph, plus a tracking sub and filtered dust. Slow independent drift on each voice.

> SEM Filter: state-variable LP → Notch → HP morph with equal-power crossfade and automatic resonance gain compensation.

> Echo: ping-pong tape delay with wow/flutter, damping, a high-pass and a soft-clipper inside the feedback loop so it can never run away.

> Space: convolution reverb with a generated impulse, energy-normalised so size changes never change level.

> Headroom: every stage is gain-staged for unity, then DC-blocked, softly saturated (4× oversampled), glue-compressed and brick-wall limited at −1 dBFS. Auto-headroom pulls back the bus if the limiter works too hard.

> Patching: drag output → input (or input → output). SHIFT+click a cable to cut it, or arm CUT.

> Keys: [ / ] preset  ·  A auto-cycle  ·  R evolve  ·  SPACE mute/unmute
